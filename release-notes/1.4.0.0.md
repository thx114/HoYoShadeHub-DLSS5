# 1.4.0.0 更新日志

> 本文件是 1.4.0.0 的 GitHub Release 正文底稿（发布时整段贴进 release body 即可）。
> 覆盖范围：v1.3.9.3 之后至今的全部改动。

## 本版（1.4.0.0）：CLI 全自动启动管线 + 插件条件云端化 + 一批界面修正

### 新：命令行 run / stopgame（插件注入不再丢）

- `HoYoShadeHub.exe run --biz hk4e_cn --json "{\"steps\":[{\"action\":\"launch_game\"}]}"` 现在走**和启动页完全相同的注入管线**（强制 hook off → DLSSG 换 310.9 → 注入器就绪后启动 → 模块 / OptiScaler / FSR Bridge 注入 → 帧率解锁），以前 CLI 启动的游戏没有任何插件。
- 含启动 / 结束游戏步骤的命令检测到非管理员运行时会**自动弹 UAC 提权**，子进程输出实时回显在你的控制台里，退出码原样传递；取消授权则什么都不执行。
- 新增 `stopgame` / `killgame` 动词和 `stop_game` 动作（先 CloseMainWindow，5 秒后强杀）。
- 支持 `--file steps.json` 从文件读动作；同一套动作词汇共 22 个接口（插件 / 预设 / ini / 启动选项 / OptiScaler / 模块 / DLL 切换 / launch_game 等），步骤级 fail-soft。详见仓库根目录 CLI.md。

### 新：覆盖包 v2 用户内容层

- 覆盖包现在可以携带**用户内容**：`ini_config.json`（每次启动幂等应用）、`auto.json` 自定义动作、`presets\`（同步进 DLSS5 预设库）、`game_files\` / `launcher_files\`（文件覆盖层）。
- 首次执行带动作的包会弹**同意窗口**：内容 hash 变化重新确认、逐项勾选默认全装、高危动作（覆盖文件 / 注册表 / 清 ini / 删滤镜）标红并展开文件清单。
- 插件页新增**预设管理卡**：预设列表 / 分享码导入（D5P1 规范互操作）/ 内置一键开关全部插件动作。

### 新：插件条件云端化（conditions.json）

- 插件判定条件（哪个插件叫什么、要不要 DllMain 加载、版本号黑名单、OptiScaler 依赖清单、内部注册名映射、DLSS5 Feed 身份）**全部从启动器代码摘离**，改由仓库 `catalog/conditions.json` 统一下发。
- 以后新增插件 / DLL 资源**只改云端配置，不发启动器版本**；离线或拉取失败时自动回落内置默认，行为与旧版完全一致（781 项自动化测试含兼容断言兜底）。
- 修复连带 bug：`renodx-dlss5-super-anus` 曾被宽前缀误判成 RenoDX DLSS5 主插件，现已显式排除。

### 新：启动游戏时自动引导游戏 ReShade.ini

- 游戏目录缺 `ReShade.ini` 时自动从当前 HoYoShade 模板补一份；ini 指向别的宿主时自动拉回；D3D12 + NR 私有交换链场景预生成第二个 runtime 的 `ReShade2.ini`，不再二次弹欢迎窗口；教程标记一并完成。

### 修：界面一批

- **游戏列表图标阴影**恢复：阴影浮起依赖的 Z 位移放回了正确元素（此前一轮「修复」把阴影留在了元素正后方，完全不可见）。
- **窗口可调宽高**：拖角缩放，最小 960×540，尺寸记忆（重启后保持）。
- **全局插件页**三个单选框不再悬空在标题和列表正中间；本地目录里未登记的插件文件列表恢复显示，且修复了**重复累积 bug**（列表每次刷新翻倍）和已下载插件被误算成孤儿的问题（全局禁用的 `.addon64x` 改名现在能正确归到插件卡片下）。
- **停止游戏按钮**改为红色实心，悬停 / 按压有明确反馈。
- DLL 页：运行时齐备时标题右侧常驻绿字；310.8.Lecram 置顶；现有 dll 一行一个；删除按钮紧贴版本名。
- 游戏列表：图标黑遮罩改为自身透明度（圆形图标不再垫黑方底）；「+」方块半透明化。
- 启动页 / 设置页：游戏目录缺 `config.ini`（常见于拷贝目录 / B 服清理）不再显示「未安装」或挡住启动，版本读取的旁路逻辑全部容忍空值。

### 修：帧率解锁（报错具体化 + 数据多版本）

- 注入失败的提示从一句笼统的「游戏版本可能更新」改为**具体原因**（权限 / PE 头 / 特征没扫到 / 远程线程失败等）。
- 游戏在附加完成前被关闭不再误报错误（之前关游戏时弹的「注入失败」其实是这个假警报）。
- 特征没扫到（上游数据滞后于游戏版本）时**自动清除同步记录**，下次启动重新拉上游，上游一适配即自愈。
- 解锁数据改为**多版本快照管理**：设置页帧率解锁区块显示当前游戏版本 / 已同步版本 / 数据更新时间，可**下拉切换历史数据版本**、一键「检查上游更新」；手动选定的旧版本不会被定时同步顶掉，上游真出新数据才自动切换。

### 修：XXMI 实例识别（版本化目录名）

- 新版 XXMI 的实例目录名带版本后缀（`ZZMI-PACKAGE-V1.4.5` 这种，不再叫裸 `ZZMI`），以前会被「实例和游戏一对一」检查误杀。现在手动指定、自动查找、实例下拉、GameBanana 装 mod 全部认版本化目录名。

### 其它

- DLSS5 预设切换器 add-on 已迁往独立仓库维护，启动器侧保留预设管理入口。
- 启动器内部重构：`GamePluginService` 统一经工厂创建（补上了漏提交的文件，新克隆可以正常编译）。
- 注入时机设置全部隐藏并固定 0（存值保留，可回滚）。
- 更新方式不变：设置 → 关于 → 更新渠道 →「GitHub · 本分支」刷新后下载安装。

**完整包**（含 HoYoShade 框架）仍只本地分发，见 README。
