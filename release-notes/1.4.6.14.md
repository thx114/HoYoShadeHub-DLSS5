# HoYoShade Hub 1.4.6.14

本次发布普通 x64 便携包，不包含 HoYoShade 框架。解压覆盖升级时保留原有用户配置和数据。

- 新增 NR 版本库与每游戏版本选择：ReShade 和 OptiScaler 可分别选择 NR，多个版本可同时开放选择；下载不会自动切换游戏版本。
- NR 通过 SHA256 识别并以硬链接共用内容；OptiScaler 按游戏隔离加载配置，切换 NR 保留质量、倍率和分辨率设置。
- PE 验证规则和 DLL 指纹支持云端独立更新，加入两个原神 V2 自制 NR 的识别与下载目录。
- 修复 NR 导入文件窗口、刷新期间无提示及版本恢复问题。构建默认 NR 不再误生成自定义卡片；默认库更新不会累积旧版卡片，删除的版本不会因刷新恢复。
- 优化 Mod 角色分类、Rocket 预览图、缩略图缩放及开关阴影；修复分类栏收起后无法打开、后端选择未保存和 Rocket 空下拉框。
- 改进独立 OptiScaler 启动、覆盖包安装保护、游戏分辨率读取及会话日志收集。
- 打包自动清理旧包与暂存目录；删除失败转移到指定 cleanup 目录，Full 流程不再重复生成普通 ZIP。

发布校验包括构建、离线回归和 ZIP 内容检查。本版未进行新的启动器交互或真实游戏验收；Windows Explorer 拖放尚未完成端到端验证。
