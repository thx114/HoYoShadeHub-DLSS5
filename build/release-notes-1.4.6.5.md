# HoYoShade Hub 1.4.6.5

恢复覆盖包至 1.4.6（1.4.6.0）原版功能，并修复两处阻止游戏启动的问题。

- 覆盖包识别、安装、动作确认、启动器设置、INI 配置和 once 账本保持 v1.4.6 原版实现，保留 runOnLaunch 行为。
- 覆盖包动作批次遇到 pending 等状态时停止该批次，游戏按现有设置继续启动；取消和页面切换仍停止启动。
- 首次启动缺少 ReShade.ini 时，在执行覆盖包初始化动作前先从宿主模板补齐，避免 set_ini_keys 因文件不存在而失败。
- 修复升级后 OptiScaler 缺少基线、遗留配置事务或双边配置变化导致的“启动配置准备失败”。启动恢复前完整备份原始配置至构建目录的 profile-recovery 文件夹。
- 有基线时保留双方修改的不同 INI 键；同键冲突或缺少基线时优先保留当前运行配置，并留存原始文件。中断的跨游戏切换从目标游戏自身配置恢复，避免串用配置。
- 恢复后的运行配置按原流程保存回所选命名预设，预设原文件和元数据也会备份。显式套用新预设仍强制应用所选配置，不被冲突恢复取消。
- 无法读取、备份或写入时仍停止配置恢复，保留原始文件并报告错误。

GitHub 提供普通 x64 便携包，Full 完整包保留本地。构建和离线测试不等于真实游戏验收。
