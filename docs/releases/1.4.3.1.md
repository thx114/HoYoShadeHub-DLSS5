# HoYoShadeHub 1.4.3.1

- DLSS5 兼容性检测优化：
  - RTX HDR 检测：当显示器未开启 Windows HDR 时直接判定为通过（绿），不再提示失效警告及弹出开启系统 HDR 按钮。
  - 显卡驱动版本：移除 616.64 驱动版本上限限制，驱动大于等于 616.56 均判定满足要求；插件管理页同步解除上限限制。
  - 移除「每游戏插件包：这个游戏在用哪一版 / 和共享目录是否同步」检测项，不再在 DLSS5 兼容性检测中提示。
- 原神帧率解锁优化：
  - 拓宽游戏设置页中「目标帧率」输入框宽度，解决输入数值时文字被右侧加减步进按钮遮挡的问题。
- 启动选项优化：
  - 移除主界面启动选项上方关于「OptiScaler 与 HoYoShade 同时启用可能出现插件冲突或兼容性问题」的提示横幅与跑马灯。
- 原神 FSR Bridge 运行库：
  - 固定渲染精度缓存为 0.6，并在配置 Bridge 时自动准备 OptiScaler 挂载状态。
