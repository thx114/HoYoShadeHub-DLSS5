# HoYoShadeHub 1.4.2

- 添加自定义游戏时，已支持的米家游戏会识别并转到原有游戏方案。
- “启用 XXMI”右侧新增设置按钮：按游戏选择手动模式或官方启动模式，并设置共用的 XXMI Launcher EXE 路径。
- 启用 XXMI 时先关闭已有启动器实例，再更新配置和启动，修正旧配置字段导致的加载配置失败。
- 修正新版 Bridge 识别及原神 OptiScaler 启动前的运行库配置准备。
- 修正完整便携包重复出现旧版本迁移引导的问题，并保留用户的窗口和启动参数设置。

## 已知问题

XXMI 与原神、崩坏：星穹铁道及 OptiScaler 的兼容问题尚未解决；注入、游戏启动或帧生成可能异常。遇到问题请暂时关闭“启用 XXMI”。本版提供可选启动流程，不承诺恢复共存。

## 下载说明

GitHub 仅提供普通版：HoYoShadeHub_Portable_1.4.2_x64.zip，包含启动器，不附带 HoYoShade 框架、OptiScaler、FSR Bridge、模块或游戏覆盖包。
完整版同时在本地打包，仅包含启动器与标准 HoYoShade 框架，不上传 GitHub。
