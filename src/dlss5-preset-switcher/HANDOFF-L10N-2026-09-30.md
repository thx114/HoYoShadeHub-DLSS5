### 2. 跟随 ReShade 语言

实现位置：`UpdateLanguage()`、`LanguageFromCode()`、`PreferredSystemLanguage()`。

行为：

1. 优先通过 ReShade 公开配置 API 读取：
   - section：`[OVERLAY]`
   - key：`Language`
2. 如果该配置不存在或为空，则使用 Windows 当前线程 UI 语言，调用：
   - `GetThreadPreferredUILanguages(MUI_LANGUAGE_NAME | MUI_UI_FALLBACK, ...)`
3. 按 BCP-47 前缀匹配语言，例如：
   - `zh-CN` / `zh-Hans` -> 简体中文；
   - `zh-TW` / `zh-HK` / `zh-Hant` -> 繁體中文；
   - `ja-*` -> 日语；
   - `ko-*` -> 韩语；
   - `fr-*` / `de-*` / `es-*` / `ru-*` -> 对应语言；
   - 未覆盖语言回退英文。
4. 每次绘制 overlay 时重新检查语言，因此在 ReShade 设置里切换语言后，插件面板和状态会更新。
5. 插件菜单标题在 add-on 加载时按当前语言注册；如果运行期间切换 ReShade 语言，菜单标题可能要重新打开 overlay 或重启游戏才更新。面板内部文本会实时更新。

不会直接修改 `ReShade.ini`。插件只用 `reshade::get_config_value` 读取语言配置。

ReShade 官方源码中已确认其 GUI 使用 `[OVERLAY] Language`，空值时使用 Windows 当前 UI 语言。相关源码：

- `https://github.com/crosire/reshade/blob/main/source/runtime_gui.cpp`
- `https://github.com/crosire/reshade/blob/main/source/dll_resources.cpp`
- `https://github.com/crosire/reshade/blob/main/source/dll_resources.hpp`
